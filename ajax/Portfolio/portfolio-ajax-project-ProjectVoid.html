Project Void

Project Info:

Project void was an intresting project I worked on while at uni, it ended up as more of a mechanic test for a start citizen inspired ship where players could freely enter and exit. Players are able to walk around and interact with physics objects with a moving ship smoothly. Ships are also able to be nested within other ships allowing me to make a little carrier. This project was fun to work on and taught me a lot, I'd be excited to pick this project back up and improve it with the knoledge I have now
